# 🏥 MediBot Assistant — Your 24/7 Digital Hospital Companion

MediBot Assistant is a comprehensive healthcare companion app designed to simplify the hospital experience for patents and visitors. Built with **Flutter**, it provides a seamless, high-fidelity user interface with a focus on accessibility and multi-language support.

## 🌟 Key Features

### 🤖 1. AI medical Chatbot
*   Interactive AI assistant for general medical Q&A.
*   Context-aware quick replies for common queries.
*   Animated typing indicators and modern message bubble UI.

### 🩺 2. Symptom Checker & Analyzer
*   Search and select from a list of common symptoms.
*   AI-driven analysis to identify potential conditions.
*   Direct recommendations for hospital departments based on results.

### 📅 3. Smart Appointment Booking
*   4-step guided wizard for scheduling visits.
*   Select departments, specialists, dates, and time slots.
*   Confirmation view with summary details.

### 🗺️ 4. Interactive Hospital Map & Navigation
*   Interactive layout visualization for all hospital floors (Ground - Floor 3).
*   Live route guidance instructions to find specific rooms or departments.
*   Floor-wise switching with color-coded accessibility indicators.

### 🚑 5. Emergency SOS System
*   One-tap emergency call button (Ambulance 102).
*   Quick-access grid for essential emergency contacts.
*   Multilingual First Aid guides for CPR, burns, and bleeding.

## 🇮🇳 Multi-Language Support

MediBot Assistant is built for local inclusivity, featuring full support for:
*   **English**
*   **Hindi (हिंदी)**
*   **Marathi (मराठी)**

Language preferences are applied instantly across all buttons, headers, descriptions, and AI instructions.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
*   [Flutter SDK](https://docs.flutter.dev/get-started/install) (Stable version recommended)
*   Android Studio / VS Code with Flutter extension
*   A physical device or emulator (Android API 30+ recommended)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ms745/health_bot.git
    cd health_bot/health_assistant_bot
    ```

2.  **Get dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the app:**
    ```bash
    flutter run
    ```

> [!NOTE]
> If you encounter build errors regarding **Android SDK version**, the project is currently configured to use **API 34** (Android 14) for maximum compatibility.
